<blockquote style="user-select: auto;">
<p style="user-select: auto;"><span style="font-size: 18px; user-select: auto;">An array is said to be&nbsp;</span><span style="font-size: 18px; user-select: auto;">palindrome</span><span style="font-size: 18px; user-select: auto;"> if its reverse array matches the original array.&nbsp;</span></p>
</blockquote>
